# Ngôi nhà số V4

Bộ công cụ quản lý gia đình chạy trực tiếp trên trình duyệt.

- 28 công cụ thuộc 10 nhóm chức năng
- Tự động lưu dữ liệu trên thiết bị
- Sao lưu và khôi phục dữ liệu
- Giao diện tương thích điện thoại, máy tính bảng và máy tính
- Không cần máy chủ hoặc cơ sở dữ liệu

Website: https://meicarevn.github.io/ngoi-nha-so/
